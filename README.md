# KI Workshop Landing Page

Eine moderne Landing Page für KI-Workshops und Beratungsangebote.

## Features

- **Hero-Section** mit überzeugendem Call-to-Action
- **Erfolgs-Raster** (2×2 Visualisierung) zur Darstellung der KI-Readiness
- **4 Workshop-Angebote**:
  - KI im digitalen Marketing
  - Web-/Front-Coding mit KI
  - Chatbots & Automatisierung
  - Context Engineering & Custom GPTs
- **Kontaktformular** für Erstgespräche
- Vollständig responsive Design

## Lokal testen

Öffne einfach die `index.html` in deinem Browser oder starte einen lokalen Server:

```bash
python3 -m http.server 8000
```

Dann öffne: `http://localhost:8000`

## GitHub Pages Deployment

### Automatisches Deployment aktivieren:

1. Gehe zu deinem GitHub Repository
2. Klicke auf **Settings** → **Pages**
3. Unter "Build and deployment":
   - Source: **GitHub Actions** auswählen
4. Pushe deine Änderungen zum Branch
5. Die Seite wird automatisch deployed

Die URL wird dann sein:
```
https://<dein-username>.github.io/studio-c/
```

## Technologie

- Pure HTML5 & CSS3
- Keine externen Dependencies
- Mobile-First responsive Design
- Moderne Gradient-Effekte

## Anpassungen

Alle Inhalte können direkt in der `index.html` angepasst werden:
- Farben: CSS-Variablen in `:root`
- Texte: Direkt im HTML
- Formular-Action: Im `<form>` Tag
